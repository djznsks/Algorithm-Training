# AGENTS

## Repository overview
- This repository is an algorithm training and learning record.
- It is organized mostly as Markdown notes and LeetCode problem write-ups.
- Key content directories:
  - `Notes/` — algorithm notes, templates, data structure and algorithm techniques.
  - `LeetCode/` — problem-specific write-ups and solutions, often in Chinese.
  - `Templates/` — reusable algorithm or solution templates.

## Agent guidance
- Treat this workspace as a study/reference repository rather than a full application or library.
- Do not assume a build system, tests, or compiled source files exist unless the user adds them.
- When asked to help, focus on:
  - editing and improving Markdown notes
  - clarifying algorithm explanations
  - generating problem solutions and code examples only when explicitly requested
- Preserve existing directory structure and Chinese file naming when adding or reorganizing content.
- If the task is unclear, ask the user for the intended output type (e.g., a markdown note, a C++ implementation, or an explanation).

## When contributing content
- Keep new content consistent with the existing style: concise algorithm descriptions, examples, and templates.
- Prefer adding new `.md` files under `Notes/` or `LeetCode/` according to the problem or algorithm category.
- Do not introduce unrelated project scaffolding or tooling.

## Existing documentation
- `README.md` explains this repository as a C++ algorithm learning record.
- There are no discovered build/test commands or language-specific toolchains in the current workspace.

## If asked to create automation
- Propose lightweight repo-specific helpers only when the user asks, such as:
  - a note template for algorithm summaries
  - a problem-solution markdown structure
  - an index of algorithms or LeetCode topics
