
> [!code]- 大数阶乘实现 - Print_Factorial (详细注释版)
> **函数功能**: 计算并打印任意正整数N的阶乘(N!)
> **算法类型**: 高精度计算（大整数运算）
> **存储方式**: 数组存储十进制数字（逆序存储）
> **时间复杂度**: O(n²)
> **空间复杂度**: O(d)，d为结果位数（d ≈ n log n）
> 
> ```c title="Print_Factorial.c"
> #include <stdio.h>
> 
> /**
>  * 计算并打印N的阶乘
>  * @param N 要计算阶乘的非负整数
>  * @note 使用数组模拟手算乘法，支持大数计算
>  */
> void Print_Factorial(const int N) {
>     // 1. 合法性判断：负数直接输出错误
>     if (N < 0) {
>         printf("Invalid input\n");
>         return;
>     }
>     
>     // 2. 特殊情况处理：0! = 1, 1! = 1
>     if (N == 0 || N == 1) {
>         printf("1\n");
>         return;
>     }
>     
>     // 3. 初始化：数组存大整数（3000位足够存1000!）
>     //    数学原理：斯特林公式估算 1000! ≈ 2568位
>     int fact[3000] = {0}; // 数组全初始化为0
>     fact[0] = 1;          // 个位先存1
>     int len = 1;          // 记录当前阶乘的有效位数（初始1位）
>     
>     // 4. 模拟手算乘法：从2乘到N
>     for (int i = 2; i <= N; i++) {
>         int carry = 0; // 进位值（比如 7*8=56，进位5）
>         
>         // 遍历当前阶乘的每一位，与i相乘
>         for (int j = 0; j < len; j++) {
>             int product = fact[j] * i + carry; // 当前位×i + 上一位的进位
>             fact[j] = product % 10;            // 保留当前位的个位
>             carry = product / 10;              // 提取进位（留给下一位）
>         }
>         
>         // 处理剩余的进位（比如进位是123，需要拆成3位存）
>         // 注意：进位可能不止一位（如 999×2=1998，进位199）
>         while (carry > 0) {
>             fact[len] = carry % 10;  // 存储当前位
>             carry = carry / 10;      // 去掉已处理的位
>             len++;                   // 有效位数加1
>         }
>     }
>     
>     // 5. 逆序输出：从高位到低位（数组末尾到开头）
>     for (int i = len - 1; i >= 0; i--) {
>         printf("%d", fact[i]);
>     }
>     printf("\n");
>     
>     // 可选：输出位数信息
>     // printf("\n（结果共%d位）\n", len);
> }
