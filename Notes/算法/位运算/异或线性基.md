
## 数学定义

给定非负整数集合 S={a1​,a2​,…,an​}，

若存在集合 B={b1​,b2​,…,bk​}，使得：

1. **张成性**
    
    S 中任意元素，都可以表示为 B 中**若干元素的异或和**；
    
    并且由 S 能异或出的所有数，都能由 B 异或得到。
    
2. **线性无关性**
    
    B 中**任意非空子集的异或和都不为 0**；
    
    即：无法用 B 中其他元素异或出 B 中某一个元素。
    
3. **极小性**
    
    满足上面两条的集合中，B 的元素个数**最少**。
    

则称 B 为集合 S 的**异或线性基**。

## 作用

#### 1. 求子集异或和的**最大值**（最常用）

- 贪心：从高位到低位，若异或当前基能让结果变大则异或。
- 例：集合 {1,2,3}，基为 {2,1}，最大异或和 = 2^1 = 3。

#### 2. 求子集异或和的**最小值**

- 若原集合能异或出 0（基大小 < 原集合大小），则最小值为 0；
- 否则，最小值为线性基中**最小的非零元素**。

#### 3. 判断一个数**能否被原集合异或得到**

- 尝试将该数插入线性基，若最终变为 0 则**能表示**，否则**不能**。

#### 4. 求异或空间的**第 k 小 / 第 k 大值**

- 先对基做**重构**（消除高位冗余，保证每一位唯一）；
- 把 k 转二进制，按位匹配基即可得到第 k 小。

#### 5. 合并两个集合的异或空间

- 将一个线性基的所有元素**插入**另一个线性基，得到合并后的基。

构建线性基：


```cpp
vector<int>b(m,0);
void insert(int x,vector<int>& b)//将x插入到线性基b中
    {
        int m=b.size();
        for(int i=m-1;i>=0;i--)
        {
            if((x>>i)&1)
            {
                if(b[i]==0)
                {
                    b[i]=x;
                    return ;
                }
                x^=b[i];
            }
        }
    }
```
