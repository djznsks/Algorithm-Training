| 运算符  | 名称   | 描述                                       | 示例                                        |     |
| ---- | ---- | ---------------------------------------- | ----------------------------------------- | --- |
| `&`  | 位与   | 对应位都为 1 时结果为 1，否则为 0                     | `6 & 3 = 2`（`0110 & 0011 = 0010`）         |     |
| \|   | 位或   | 对应位有一个为 1 时结果为 1，否则为 0                   | 6 \| 3 = 7`（`0110 \| 0011 = 0111）         |     |
| `^`  | 按位异或 | 对应位不同时结果为 1，相同时为 0（特性：`x^x=0`，`x^0=x`）   | `6 ^ 3 = 5`（`0110 ^ 0011 = 0101`）         |     |
| `~`  | 按位取反 | 所有位取反（0 变 1，1 变 0；注意：有符号数会涉及补码，结果可能是负数）  | `~6 = -7`（`~0110 = 1001`，补码表示 -7）         |     |
| `<<` | 左移   | 所有位向左移 n 位，右边补 0（等价于乘以 2^n，效率更高）         | `====6 << 1 = 12====`（`0110 << 1 = 1100`） |     |
| `>>` | 右移   | 所有位向右移 n 位，正数左边补 0，负数左边补 1（等价于除以 2^n 取整） | `6 >> 1 = 3`（`0110 >> 1 = 0011`）          |     |
### 判断奇偶性

==一个数的二进制最后一位是1则这个数是奇数；是0则为偶数；==

n & 1  == 0            表明n为偶数
n & 1  == 1            标明n为奇数

### 统计n二进制中1的个数

```c
	int ans=0;
	while(n>0)
	{
		ans++;
		n=n&(n-1);
	}
	return ans;
```
### 交换两个数的值

a ^= b     # a = a ^ b
b ^= a     # b = b ^ a = b ^ (a ^ b) = a
a ^= b     # a = a ^ b = (a ^ b) ^ a = b
