## 三种表示方法

### 1. 原码（Sign-Magnitude）

- 最高位表示符号（0正1负），其余位表示数值
    
- 例如（8位）：`+5 = 00000101`，`-5 = 10000101`
    
- 问题：有两个零（+0和-0），运算复杂
    

### 2. 反码（One's Complement）

- 正数不变，负数：符号位不变，其余位取反
    
- 例如（8位）：`+5 = 00000101`，`-5 = 11111010`
    
- 问题：仍有+0和-0的问题
    

### 3. 补码（Two's Complement）✅ **现代计算机使用**

- 正数不变
    
- 负数：**取反 + 1**
    
- 只有一个零，运算简单
    

## 补码的规则

**求一个数的补码：**

1. 写出该数的绝对值二进制
    
2. 按位取反（0变1，1变0）
    
3. 加1
    

### 具体示例（8位）

 ```cpp

// 求 -5 的补码
+5  = 00000101
取反 = 11111010
加1  = 11111011  // -5 的补码
// 验证：5 + (-5) = 0
 00000101  // +5
+11111011  // -5
=100000000  // 溢出，结果是 00000000 ✅

### 更多例子

cpp

// 8位表示范围：-128 ~ 127
+1  = 00000001
-1  = 11111111  // 00000001 取反+1
+2  = 00000010
-2  = 11111110
+127 = 01111111
-127 = 10000001
-128 = 10000000  // 特殊的，没有对应的正数

## 为什么用补码？

1. **统一加减法**：减法可以转化为加法
    
    text
    
    a - b = a + (-b)
    
2. **唯一零**：只有 `00000000`
    
3. **硬件简单**：只需要加法器
    

## lowbit 在负数中的应用

cpp

int lowbit(int x) {
    return x & -x;  // x 与 -x 按位与
}

### 示例分析

cpp

// 假设 x = 6 (110)
x  = 6  = 00000110
-x = -6 = 11111010  // -6 的补码
x & -x = 00000010   // 结果是 2 (lowbit)
// 假设 x = 8 (1000)
x  = 8  = 00001000
-x = -8 = 11111000
x & -x = 00001000   // 结果是 8 (lowbit)

### 原理解释

`-x` 的二进制是 `~x + 1`（取反加1）：

- `x` 最右边的1的位置，在 `~x` 中是0
    
- 加1会使得这个位置变成1，并且进位停止
    
- 所以 `x & -x` 保留的就是最右边的1
    

## 实际应用场景

cpp

// 打印负数的二进制表示
#include <bitset>
#include <iostream>
using namespace std;
int main() {
    int x = -5;
    cout << bitset<8>(x) << endl;  // 11111011
    
    // 验证
    int y = 5;
    cout << bitset<8>(y) << endl;   // 00000101
    
    cout << bitset<8>(x + y) << endl; // 00000000
}

## 注意事项

1. **不同位数**表示范围不同：
    
    - 8位：-128 ~ 127
        
    - 16位：-32768 ~ 32767
        
    - 32位：-2147483648 ~ 2147483647
        
2. **溢出**：超出范围会产生错误结果
    
3. **移位操作**：负数的右移是算术右移（补符号位）
    

cpp

int x = -8;      // 11111000
int y = x >> 2;  // 11111110 = -2 (算术右移)
 ```
## 总结

- 负数用**补码**表示：`补码 = 取反 + 1`
    
- `x & -x` 利用了补码特性，可以得到最低位的1
    
- 补码让加法和减法统一，简化了硬件设计
