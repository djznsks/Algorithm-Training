
**按位运算 &、|、^ 本质上就是集合运算**：

- 按位与 `x & y` ↔ 集合**交集** A∩B
- 按位或 `x | y` ↔ 集合**并集** A∪B
- 按位异或 `x ^ y` ↔ 集合**对称差** A△B(即只在A或者只在B里面)

x | (y & z) = (x | y) & (x | z) 
x & (y | z) = (x & y) | (x & z)
x & (y ^ z) = (x & y) ^ (x & z)


a & b == 0，就代表 a 和 b 二进制位完全不重复、不重叠！
举例子：

- 3 = **11**
- 1 = **01**

它们**最低位都是 1** → **位重复了**

所以 `3 & 1 = 1 ≠ 0` → **重复**

- **`|=` 按位或赋值**
    
    `a |= b` → 把 `b` 的二进制位**合并加入**到 `a` 里(不管重复或不重复都可以用)

- **`^=` 按位或赋值**
    
    `a ^= b` → 把 `b` 的二进制位从 `a` 里**删除**(只能不重复时才能用)




用一个小例子彻底看懂：

plaintext

```
窗口：[1, 2]
1 → 01
2 → 10
or_ = 01 | 10 = 11 (3)
```

### 执行删除 1：

plaintext

```
or_ ^= 1
11 ^ 01 = 10 → 背包里只剩 2
```

### 执行添加 4：

plaintext

```
or_ |= 4
10 | 100 = 110 → 背包里有 2、4
```


这两行就是**滑动窗口 + 位掩码**的灵魂：

- **`|=` 进窗口**
- **`^=` 出窗口**



例题：求数组中相互二进制不重复的最长子数组个数

```c
class Solution {
public:
    int longestNiceSubarray(vector<int>& nums) {
        int ans = 0, left = 0, or_ = 0;
        for (int right = 0; right < nums.size(); right++) {
            while (or_ & nums[right]) { // 有交集
                or_ ^= nums[left++]; // 从 or 中去掉集合 nums[left]
            }
            or_ |= nums[right]; // 把集合 nums[right] 并入 or 中
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};

```
