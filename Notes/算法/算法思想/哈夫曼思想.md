
**核心思想**：

每次从所有数据里**选出两个最小的数**，把它们加起来，得到一个新数；

把新数放回集合里，重复上面操作，直到只剩一个数。

全程就是**贪心：每次合并当前最小两个**，用来求最小总代价、最优合并开销。

# C++ 极简实现

原理：用**小根堆**每次取两个最小值相加，累加总开销，就是哈夫曼思想的本质。



运行

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main()
{
    // 小根堆：默认优先队列是大根堆，改成小根堆
    priority_queue<int, vector<int>, greater<int>> q;

    // 输入一组权值
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        int x;
        cin >> x;
        q.push(x);
    }

    int sum = 0;
    // 哈夫曼核心：剩一个数就停止
    while (q.size() > 1)
    {
        // 取出最小两个
        int a = q.top(); q.pop();
        int b = q.top(); q.pop();

        // 合并
        int c = a + b;
        sum += c;   // 累加合并代价
        q.push(c);  // 新值放回堆里
    }

    // 输出最小总代价
    cout << sum << endl;
    return 0;
}
```
