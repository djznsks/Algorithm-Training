### 升级版例题


📊 差值统计算法

📌 代码文件信息
- **文件类型**：C++ 源代码
- **主要功能**：统计数组中差值在特定范围内的元素对数量
- **算法思想**：排序 + 双指针

#### 📝 代码实现
```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;
using ull = unsigned long long;
using db = double;
#define ff(n) fixed << setprecision(n)
#define PI acos(-1.0)

int main() {
    ios::sync_with_stdio(false), cin.tie(nullptr), cout.tie(nullptr);
    int n, d;
    cin >> n >> d;
    vector<int> a(n);
    
    // 读取数组
    for (int i = 0; i < n; i++) 
        cin >> a[i];
    
    // 排序数组（升序）
    sort(a.begin(), a.end());
    
    int cnt = 0;
    
    // 双指针统计
    for (int i = 0, b = 0, c = 0; i < n; i++) {
        // 指针b：找到满足 a[i] - a[b] >= d 的第一个位置
        while (b <= i && a[i] - a[b] >= d) 
            b++;
        
        // 指针c：找到满足 a[i] - a[c] > d 的第一个位置
        while (c <= i && a[i] - a[c] > d) 
            c++;
        
        // 统计差值在 (d, ∞) 范围内的元素对数量
        cnt += b - c;
    }
    
    cout << cnt;
    return 0;
}




🧠 算法解析

核心思路

统计数组中满足 d < a[i] - a[j] ≤ ∞（即 a[i] - a[j] > d）的元素对 (i, j) 的数量，其中 i 是当前元素索引。

指针含义

1. 指针 b：
   · 维护满足 a[i] - a[b] >= d 的最小索引
   · 即 b 是第一个使得 a[i] - a[b] 不再小于 d 的位置
2. 指针 c：
   · 维护满足 a[i] - a[c] > d 的最小索引
   · 即 c 是第一个使得 a[i] - a[c] 不再小于等于 d 的位置

统计原理

· b - c 表示满足 d < a[i] - a[j] ≤ ∞ 的 j 的数量
· 对每个 i 累加，得到总的符合条件的元素对数量

🔍 时间复杂度分析

· 排序：O(n log n)
· 双指针遍历：O(n)
· 总复杂度：O(n log n)


这一题相当于优化版的二分查找
```

### 超级版例题

算法思路说明

问题理解

这是一个双序列组合问题，目标是在一个有序数组中，找到两个不相交的子序列（一个在左，一个在右），使得每个子序列内任意两元素差值不超过k，并且两个子序列长度之和最大。

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;
using ull = unsigned long long;
using db = double;
#define ff(n) fixed << setprecision(n)
#define PI acos(-1.0)

const int N = 5010;
int lr[N];  // lr[i]: 以 i 结尾的最长合法左子序列长度
int rl[N];  // rl[i]: 以 i 开始的最长合法右子序列长度
int a[N];   // 存储原始数组

int main() {
    ios::sync_with_stdio(false), cin.tie(nullptr), cout.tie(nullptr);
    
    int n, k;
    cin >> n >> k;
    
    // 输入数组，下标从1开始
    for(int i = 1; i <= n; i++) 
        cin >> a[i];
    
    // 初始化两个DP数组
    memset(lr, 0, sizeof lr);
    memset(rl, 0, sizeof rl);
    
    // 计算lr数组：从左向右扫描
    // lr[i] 表示考虑前i个元素，以i结尾的最长合法子序列长度
    for(int i = 1, j = 1; i <= n; i++) {
        // 维护滑动窗口：a[i] - a[j] <= k
        while(j < n && a[i] - a[j] > k) 
            j++;
        // lr[i]取前一个最大值和当前窗口长度的较大值
        lr[i] = max(lr[i-1], i - j + 1);
    }
    
    // 计算rl数组：从右向左扫描
    // rl[i] 表示从i开始向右的最长合法子序列长度
    for(int i = n, j = n; i > 0; i--) {
        // 维护滑动窗口：a[j] - a[i] <= k
        while(j > 0 && a[j] - a[i] > k) 
            j--;
        rl[i] = max(rl[i+1], j - i + 1);
    }
    
    // 寻找最大组合值
    int res = 0;
    for(int i = 1; i <= n; i++) 
        res = max(rl[i] + lr[i-1], res);  
    
    cout << res;
    return 0;
}
```
