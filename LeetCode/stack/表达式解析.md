# 2. 题目描述

给定一个整数 n，按照以下规则计算：

n * (n-1) / (n-2) + (n-3) - (n-4) * ...

运算符按照：

*
/
+
-

循环使用。

要求返回最终结果。

示例：

输入：
n = 4

计算：
4 * 3 / 2 + 1

输出：
7


---

# 3. 思路分析

## 我的第一想法：

直接模拟表达式计算。

但是问题：

- 乘除优先级高于加减
- 需要保存之前的计算结果


## 核心思想：

使用栈模拟。

栈中保存：

- 当前已经计算好的数字
- 最后统一求和


例如：

n = 10

表达式：

10 * 9 / 8 + 7 - 6 * 5 / 4 + 3 - ...


操作：

1. 遇到 *
   - 弹出栈顶
   - 乘当前数字
   - 放回栈

2. 遇到 /
   - 弹出栈顶
   - 除当前数字
   - 放回栈

3. 遇到 +
   - 当前数字直接入栈

4. 遇到 -
   - 当前数字取负后入栈


最后：

栈内全部元素求和。


---

# 4. 算法流程

1. 初始化栈

stack = [n]


2. 从 n-1 开始遍历

每次根据操作符处理：


操作编号：

0 -> *

1 -> /

2 -> +

3 -> -


3. 操作完成后：

op = (op + 1) % 4


4. 返回：

sum(stack)

# 5. C++代码


```cpp
class Solution {
public:

    int clumsy(int n) {

        stack<int> stk;

        stk.push(n);

        int op = 0;


        for(int i = n - 1; i >= 1; i--){

            if(op == 0){

                int x = stk.top();
                stk.pop();

                stk.push(x * i);

            }
            else if(op == 1){

                int x = stk.top();
                stk.pop();

                stk.push(x / i);

            }
            else if(op == 2){

                stk.push(i);

            }
            else{

                stk.push(-i);

            }


            op = (op + 1) % 4;
        }


        int ans = 0;

        while(!stk.empty()){

            ans += stk.top();

            stk.pop();

        }


        return ans;
    }
};
